# 🚨 POLÍTICA: SIEMPRE GRATIS

**Regla absoluta**: TODA herramienta, API, servicio o integración debe ser 100% GRATUITA.

## Prohibido
- ❌ APIs de pago sin tier gratuito
- ❌ Suscripciones
- ❌ Créditos de prueba que expiran
- ❌ Servicios con límites de pago obligatorio

## Permitido (tiers gratuitos)
- ✅ Gemini API: 1500 req/día
- ✅ Firebase Spark: 1GB, 50K reads/día
- ✅ Google Colab: GPU T4, 12h/sesión
- ✅ GitHub Actions: 2000 min/mes
- ✅ Oracle Cloud Free: 4 ARM cores, 24GB RAM
- ✅ Cloudflare: 100K req/día
- ✅ n8n: self-hosted
- ✅ Home Assistant: open source
- ✅ MQTT: open source
- ✅ ESPHome: open source

## Verificación
Antes de usar cualquier servicio, verificar:
1. ¿Tiene tier gratuito?
2. ¿Cuáles son los límites?
3. ¿Se puede self-host?
4. ¿Hay alternativa open source?
