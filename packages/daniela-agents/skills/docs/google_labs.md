# Skill: Google Labs

Controla todos los servicios de Google Labs.

## Capacidades
- NotebookLM: crear y consultar cuadernos
- MusicFX: generar música
- Whisk: generar imágenes
- Test Kitchen: probar recetas
- Project Tailwind: generar código
- Veo: generar videos
- Imagen: generar imágenes

## Uso
```python
from phone.agents.google.labs.labs import LabsAgent

labs = LabsAgent()
result = labs.run()
```
