# Skill: Social Media

Publica contenido en todas las redes sociales automáticamente.

## Capacidades
- TikTok: subir videos con descripción y hashtags
- Twitter/X: publicar hilos y tweets con imágenes
- Instagram: subir fotos, reels y stories
- LinkedIn: publicar artículos profesionales
