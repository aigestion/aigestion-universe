```python
# ¡el error de verdad DESAPARECE!
```

`wave.open(..., "wb")` **como context manager sustituye la excepción original**: su
`__exit__` intenta parchear la cabecera, falla, y tapa el error real. **Repro
comprobado a mano antes de tocar nada.** Arreglo: **abandonar el `with`** y cerrar a
mano para que la excepción original sobreviva. (Envolver el `with` en try/except **no
sirve**: `__exit__` corre antes del handler.)

**Segundo problema del mismo sitio:** `wave` deja un **WAV de 0 bytes** si falla. Un
fichero corrupto que *parece* bueno es **peor que no tener fichero** → `unlink(missing_ok=True)`.
Esto lo encontró un test que afirmaba **después** de que el `TemporaryDirectory` se
hubiera limpiado (el test también estaba mal; se corrigió moviendo los asserts dentro).
